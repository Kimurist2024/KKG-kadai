# バックエンドの回帰テスト

| 場所 | 検証対象 |
|---|---|
| `analyzer/` | 面積・壁・扉の集計、壁の警告 |
| `geometry/` | 線分の射影・区間処理・候補検索 |
| `topology/` | 穴・重複領域 |
| `main/` | 解析 API の正常系・異常系 |
| `performance/` | 変更前の実装との数値比較 |
| `conftest.py` | 同梱サンプルの読込とキャッシュのテスト間隔離 |
| `factories.py` | 小さな入力データを組み立てる共通ヘルパー |

アプリ直下から `(cd backend && .venv/bin/python -m pytest -q)` で実行します。

変更前との数値一致は、変更で結果が変わっていないことの確認です。アルゴリズムそのものの正しさは、同梱サンプルと境界条件のテストで別に確認します。
