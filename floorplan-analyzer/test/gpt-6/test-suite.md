# GPT-6 管理のテスト

既存テストを frontend/・backend/ に集約しています。ディレクトリ名は管理区分であり、既存テストすべての作成モデルを示すものではありません。

## 部分スクロールの回帰テスト

追加テストの作成モデル: GPT-6

`frontend/partialScroll.test.tsx` は Vitest / React Testing Library / jsdom で以下を確認します。

- 確認事項が図面パネルに属し、見出し・計算条件はスクロール内容の外にあること。
- 実際の CSS を適用した両領域に高さ制限、標準スクロール、スクロール連鎖の抑制、キーボードフォーカスが設定されていること。
- 部屋選択後のフィット、200% 拡大、画面高さ変更でも図面の表示枠が内容に合わせて伸びず、解析 API を再実行しないこと。

フロントエンドのディレクトリで実行してください。

```sh
cd floorplan-analyzer/frontend
npx vitest run ../test/gpt-6
```

既存テストを含む全件は `npm test` で実行します。既存の `frontend/planPan.test.tsx` はドラッグ移動・端での位置制限・クリックとの区別を検証します。

解析 API は既存の結果フィクスチャでモックしています。面積アルゴリズムの正しさを検証するテストではありません。

jsdom はレイアウトや標準のホイールスクロールを実行しません。そのため、CSS 設定とコンポーネントの状態・寸法の検証までを対象とし、Safari 等での実スクロール、ページへの連鎖抑制、描画のちらつきは実ブラウザでの別途確認が必要です。
