# README の文章の判断基準

1. 読み手はインターン選考の採点者。応募者本人が自分の判断を自分の言葉で説明している文として読めるかで良し悪しを決める。
2. 書いてよいのは、リポジトリか実測で裏が取れる事実だけ。「自分で判断した」と書く内容は、本人が実際に出した指示に基づくものに限る。
3. 数値は、配布された同梱データで読み手が確かめられるものを優先する。確かめようのない人工データの倍率は載せない。
4. 「〜ではありません」「〜わけではありません」「保証できません」のように先回りして否定する文は、何をしているかを述べる肯定文にする。結果や仕様をそのまま述べる否定（「窓は控除していません」）は残してよい。
5. 「限界」「あくまで」のような決まり文句と、読めば分かる自明な説明は書かない。
6. 足すかどうかは、課題文が求める 5 項目（プロンプト・実装上の工夫・検証方法・自分で判断し改善した点・参考文献）のどれに効くかで決める。どれにも効かない文は足さず、迷ったら削る。
7. 頼まれた箇所以外の見出し・リンク・数値・コードは変えない。変わるときは、1 つずつ理由を言えること。
8. サンプルの結果は `floorplan-analyzer/docs/validation/sample-results.md` と一致していること。
9. 文体はです・ます。README の 3 章以降は、和文と英数字の間に空白を入れない。
10. 受入条件には、実際の差分と一致する内容だけを書く。レビューは文言をそのまま適用するので、曖昧な条件や実態と違う条件は書かない。
